# Adam Galerie Salát 🥗📸

Jednoduchá webová galerie fotek seřazená chronologicky podle data pořízení (EXIF) s možností přidávat nové fotky přes Telegram bota.

## Funkce
- 📅 **Řazení podle data focení** – fotky se řadí podle skutečného data v EXIF metadatech, ne podle data nahrání.
- 🤖 **Telegram Bot** – možnost poslat novou fotku přímo z mobilu přes Telegram bota.
- ⚡ **Vercel** – hosting webové aplikace a serverless webhook pro Telegram bota.
